# Contributing

Thanks for your interest in Yggdrasil.

## Setup

Clone the repo with all submodules:

```sh
git clone --recurse-submodules git@github.com:yggdrasil-hq/yggdrasil-core.git
```

## Keeping docs in sync

AI is widely used to contribute to this codebase, which means documentation is load-bearing. If your change affects how something works — structure, conventions, data flow — update the relevant doc alongside it.

Each submodule has a `CLAUDE.md` with a routing table pointing to its docs. When in doubt, that's where to start.
