Wireframe · maps to /settings/organization/secrets — split out of the old single-page tab set, see General's design-note for the IA rework itself. Org-level secrets shared across every project are a new concept, modeled after the same org-owns/project-inherits pattern this Settings group already proposes for Providers & Models — no more and no less grounded than that. Project-level secrets (the project-only kind a project can add on top of these) are real, though: job-dispatch.md already has the API decrypting project_secrets and injecting them into job pods — see a project's own Settings → Secrets for that side of it, and that page's design-note for how a feature's spec_grill requesting one as an action item is meant to close the loop.
