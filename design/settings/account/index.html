Wireframe · maps to /settings/account (web/app/settings/account/page.tsx) · IA rework round 3: top hub-header replaced by the same persistent sidebar as every other page — this page is now reached via the sidebar account cell's dropdown rather than a separate user-menu (see /projects's design-note for the full rationale) · relaid out from one long scroll into a sectioned settings page (Profile / Providers & Models) — CSS-only radio-toggle tabs, same technique as the /projects/new stepper · superseded pass: this page previously had full multi-provider/multi-model CRUD (connect providers, add models, set per-job defaults) as a proposed rework of ADR 007's single-bundle design. Now that /settings/organization exists, that CRUD moved there and admin-managed — letting individual members configure their own provider keys would undercut the whole point of centralizing on an audited, admin-controlled set of connections (and directly contradicts the "scoped, admin-controlled access" story the landing page now makes). This page is read-only, showing what the org has made available, with a link out to Organization settings for whoever can actually change it. design_grill row dropped from the job-defaults list here for brevity (still present in the org settings page) — not implemented yet either way (ADR 014). None of this exists in ADR 007 or the api/web model-secrets code; ADR 007 itself will need a full rewrite (or replacement) once an Organization entity is real, since its central premise — "no team/org entity yet" — no longer holds. Added Usage and Analytics sections as the user-level tier of /usage and /analytics (folded into Account settings rather than given their own top-level nav item, since "your personal usage/activity" reads as an account concern, not a primary destination) — same "nothing here is tracked today" caveat as those two pages, see their design-notes for the full explanation. Framed the same way as project-level Usage: your numbers are a slice of Acme Retail's shared quota, not a separate one — no independent limit or reset date shown here.
