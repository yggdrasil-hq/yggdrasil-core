ADR: Saved payment methods

Context
Customers re-enter card details on every purchase. Repeat customers should be able to save a card.

Decision

Tokenize cards via Stripe SetupIntent. Store payment_method id + last4/brand only. Add a default_payment_method_id on the customer record, allow marking one card default. Removing the default requires picking a new one first.

Grill finished · spec_ready Stop only applies while a grill is running
Agent

I'll spec out saved payment methods. First — should we support more than one saved card per customer, or just one?

You

Multiple cards, with one marked default.

Agent

Got it. I'll use a Stripe SetupIntent to tokenize the card without touching raw PAN data, store only the Stripe payment_method id + last4/brand, and add a `default_payment_method_id` on the customer record. Should removing the default card auto-promote another saved card, or require the customer to pick a new default first?

You

Require picking a new default first — don't guess for the customer.

Agent

ADR drafted. Ready for your review.
