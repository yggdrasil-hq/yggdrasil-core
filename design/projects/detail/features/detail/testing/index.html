Wireframe · maps to /projects/:projectId/features/:featureId/testing — an entirely new route/gate, run automatically once Implementation finishes, per the user's spec ("all configured Unit/Integration/Agentic tests for the project"). Grounding is mixed by group: Agentic maps directly to the existing Tests feature — a real per-project test_run job, markdown spec, agent-executed (see /tests). Unit and Integration have no equivalent anywhere — there's no CI/code-level test runner concept in any ADR, no config for one, and no job kind that would execute npm test / pytest-style tests inside a container. Showing them here is entirely aspirational. This feature hasn't reached Testing yet (still Implementing), so the honest default view is empty; pass/fail results are previewed below for reference only.
