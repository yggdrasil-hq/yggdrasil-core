Wireframe · maps to /projects/:projectId/features/:featureId/agentic-review — an entirely new route/gate/job with no grounding anywhere. Unlike Testing (which at least has a real Agentic-test sibling) or the Action Item types (each traceable to something that exists), there is no ADR, no job kind, no skill, and no contract-tool event for "an agent reviews another agent's diff" — this page is a pure proposal for what the user described as a gate between Testing and Manual Review. It would presumably need its own job kind (something like agentic_review), its own skill/image, and its own curated event vocabulary, none of which this wireframe attempts to design. This feature hasn't reached this stage yet (still Implementing), so the default view is honestly empty; Approved/Changes-requested are previewed below only to show the shape of the idea.
